## 🏗️ Microservices Architecture & Endpoints

DateSpark uses a decoupled microservices architecture to manage heavy AI reasoning and fast UI delivery efficiently.

### 1. Gateway Service (Node.js / Express)
Orchestrates requests between the frontend and internal services, handling authentication, payments, and standard operations.

**Endpoints:**
- **Itinerary & Discovery**
  - `POST /api/generate-date` - Generates a standard guided date plan.
  - `POST /api/generate-custom-date` - Generates a custom date plan based on open parameters.
  - `POST /api/recreate-date` - Recreates a specific existing plan.
  - `POST /api/nearby-alternatives` - Suggests nearby alternative venues.
  - `GET /api/trending-plans` - Fetches global trending plans.
  - `GET /api/search` - Searches existing plans.
  - `GET /api/user-plans` - Retrieves plans generated by a specific user.
  - `GET /api/plans/:id` - Fetches the details of a specific plan.
  - `PATCH /api/update-plan` - Updates plan details.
  - `POST /api/delete-plan` - Deletes a user plan.
  - `POST /api/plans/:id/boost` - Boosts a plan's popularity.
  - `POST /api/plans/:id/try` - Increments a plan's 'try' count.
  - `POST /api/swap-venue` - Swaps an individual venue within an itinerary.
  - `GET /api/recommendations/:userId` - Fetches personalized recommendations.
- **AI Streaming & Concepts**
  - `POST /api/architect-stream` - Streams an interactive chat response from the Date Architect AI.
  - `POST /api/suggest-date-concepts` - Analyzes chat history to suggest immediate Date Concepts.
- **Events**
  - `GET /api/events` - Hybrid multi-source event fetcher (Ticketmaster, SeatGeek, SerpApi).
- **Payments (Stripe)**
  - `POST /api/create-checkout-session` - Creates a checkout session for Passes/Plus.
  - `POST /api/create-portal-session` - Opens the Stripe Customer Portal.
  - `POST /api/webhook` - Listens to Stripe events for fulfillment.
- **Users & Account**
  - `POST /api/increment-save-usage` - Validates and increments weekly save limits.
  - `GET /api/user-premium/:userId` - Checks premium subscription status.
  - `GET /api/user-usage/:userId` - Retrieves usage limits and quotas.
  - `POST /api/forgot-username` - Email delivery for forgotten usernames.
  - `POST /api/send-welcome` - Delivers the welcome email upon sign-up.
  - `POST /api/upload-avatar` - Uploads profile avatars to storage.
  - `POST /api/feedback` - Handles application feedback.
- **Utility**
  - `GET /api/photo-proxy` - Proxies Google Places Photo requests to bypass cross-origin browser limits.
  - `GET /api/health` - Basic health check.

### 2. AI Microservice (Python / FastAPI)
A dedicated environment for handling heavy AI processing, prompt engineering, and model failovers (Gemini 2.5 Pro → OpenAI fallback).

**Endpoints:**
- `GET /health` - Verifies AI service operational status and loaded provider API keys.
- `POST /generate-itinerary` - Takes raw natural language or structured data and builds the JSON date plan format using the "Date Architect" prompt.
- `POST /chat` - Real-time conversational endpoint connecting to Gemini/OpenAI.

### 3. Core Modules
- `itineraryService`, `eventService`, `paymentService`, `userService`, `generationService`, `emailService`: Encapsulated logic bridging the Gateway and external APIs / Supabase.

## 🧪 Unit Testing Strategy

Unit testing involves testing individual units or components of the software in isolation to ensure they function precisely as intended. For DateSpark, we can implement the following testing strategy:

### Types of Unit Testing We Can Perform:
1. **Service Logic Tests (Backend):** 
   - Mocking database (`Supabase`) and third-party API (`Stripe`, `Resend`, `Google Places`) interactions inside our Core Modules. 
   - *Example:* Testing `userService.checkUsageLimits` to ensure it correctly denies requests when a free user exceeds their weekly quota.
2. **API Endpoint Routing Tests:** 
   - Using tools like `Supertest` (for Express) and `pytest-fastapi` (for the Python microservice) to validate that our endpoints return the correct HTTP status codes and JSON structures given valid and invalid request bodies.
3. **Frontend Component Tests:** 
   - Using `React Testing Library` and `Vitest`/`Jest` to mount components like the `ItineraryCard` or `VisualSparkCard` in isolation. 
   - *Example:* Asserting that a fallback image renders correctly when the primary Google Place photo URL is broken or missing.
4. **Utility & Pure Function Tests:** 
   - Testing date/time parsers, distance calculators, and custom React hooks (`useABTest`) for predictable outputs without any external dependencies.

### Why Unit Testing is Important:
- **Prevents Core Regressions:** It acts as a safety net. If someone modifies the `generationService` and accidentally breaks the JSON parsing logic, unit tests will catch it before it reaches production.
- **Enables Confident Refactoring:** As we scale (e.g., adding a new AI provider), tests ensure the new implementation still fulfills the exact same requirements as the old one.
- **Pinpoints Failures Quickly:** Because tests are isolated, if a test fails, you know *exactly* which module or function is broken, bypassing hours of manual debugging.
- **Living Documentation:** Well-written tests demonstrate exactly how functions and components are meant to be used, acting as a guide for new developers onboarding onto the codebase.

## ⚙️ Setup & Infrastructure

### 1. Environment Configuration
Create a `.env` file in the root directory with the following keys:

```env
# Server Config
PORT=5000
FRONTEND_URL=https://datespark.live
SUPABASE_URL=...
SUPABASE_SERVICE_ROLE_KEY=...

# Client Config
VITE_SUPABASE_URL=...
VITE_SUPABASE_ANON_KEY=...
VITE_GOOGLE_MAPS_API_KEY=...
VITE_STRIPE_PUBLISHABLE_KEY=pk_live_...

# AI & Third Party
GEMINI_API_KEY=...
OPENAI_API_KEY=...
RESEND_API_KEY=...
STRIPE_SECRET_KEY=sk_live_...
STRIPE_WEBHOOK_SECRET=whsec_...
```

### 2. Installation
```bash
npm install
cd backend/ai_service && pip install -r requirements.txt
```

### 3. Execution
```bash
# Start Frontend Server
npm run dev

# Start Node.js API Gateway
node backend/index.js

# Start Python AI Microservice
cd backend/ai_service && uvicorn main:app --port 8001
```
